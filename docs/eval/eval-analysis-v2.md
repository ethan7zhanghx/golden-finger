## 一、失败类型清晰分层

### 1.1 失败分类定义

| 失败类型 | 定义 | 发生阶段 | 是否内容质量问题 |
|---------|------|---------|---------------|
| **FORMAT_ERROR** | API 响应成功，但输出非纯 JSON（有 markdown 包裹或文本前缀） | 生成阶段 | 否，是格式问题 |
| **JUDGE_ERROR** | 生成成功且 schema 通过，但 Judge 响应也非纯 JSON | 评测基础设施 | **否**，eval 自身 bug |
| **SCHEMA_ERROR** | JSON 解析成功，但缺少必填字段 | 生成阶段 | 是（结构问题） |
| **API_ERROR** | HTTP 错误、超时等 | 网络/认证 | 否 |
| **QUALITY_LOW** | schema 通过、judge 成功、但内容得分 < 65 | 内容质量 | 是 |

### 1.3 关键更正

> **JUDGE_ERROR ≠ 内容质量差**
>
> 检查 JUDGE_ERROR 的原始响应，Judge 模型实际上生成了有效评分内容（如 `{"scores": {"specificity": 5, "consistency": 5...}`），但响应前后有额外文字导致解析失败。这是 **eval 脚本的 bug**（JSON 提取逻辑不够鲁棒），不是内容质量问题。

> 上版报告将这些轮次按 score=20 计入质量分，导致质量均值被人为拉低。**上版质量分（ernie 69.1, ds 67.5）不可信。**

## 二、失败根因分析（Badcase）

### 2.1 FORMAT_ERROR — 根因与复现规律

**根因**：ERNIE-5.0 和 DeepSeek-V3.2 均会在特定条件下在 JSON 外添加 markdown 代码块（\`\`\`json ... \`\`\`）或文本说明，即使 system prompt 明确要求"严格的 JSON 格式"。

**DeepSeek-V3.2 高发题材**（FORMAT_ERROR 14次 中的分布）：

| 题材 | 失败轮次/总轮次 | 失败率 |
|------|---------------|--------|
| G09 重生复仇 | 3/3 | **100%** |
| G10 校园青春 | 3/3 | **100%** |
| G02 总裁甜宠 | 2/3 | 67% |
| G08 赛博朋克 | 2/3 | 67% |
| G01 都市逆袭 | 2/3 | 67% |
| G04 玄幻修真 | 1/3 | 33% |
| G03 古装权谋 | 1/3 | 33% |

**观察**：DeepSeek 在校园、重生、赛博朋克题材上 **100% 格式失败**，而在职场(G07)、家庭(G06)、悬疑(G05)上 100% 格式通过。疑似与 prompt 长度、中文语义密度或题材特征有关，需要对这3个题材单独做消融测试。

**ERNIE-5.0 FORMAT_ERROR**（4次）：
- G01 都市逆袭 R3、G02 总裁甜宠 R1、G06 现代家庭 R1+R2
- 呈随机分布，非系统性失败

**修复方案（优先级排序）**：
1. **立即可做**：在 prompt system 最后一行加 `「重要：直接输出 JSON 对象，首字符必须是 {，不得有任何前置说明、代码块标记或注释」`
2. **后处理兜底**：改进 `extract_json()` 函数，增加 fallback（查找第一个 `{` 到最后一个 `}`）
3. **DeepSeek 专项**：对 G09/G10/G08 题材增加 few-shot 示例（1个正确 JSON 示例）

### 2.2 JUDGE_ERROR — 根因与修复

**根因**：eval 脚本的 `extract_json()` 函数在 Judge 响应存在前置文字（如"以下是评分结果："）时提取失败，即使 JSON 内容本身完整有效。

这是 **eval 基础设施 bug**，而非内容问题。

**修复**：改进 `extract_json()`：
```python
def extract_json(text):
    # 1. 去 markdown 块
    # 2. 找第一个 { 的位置，从那里开始尝试解析
    # 3. 如果整体解析失败，尝试逐渐截断末尾后重试
```

### 2.3 内容质量 Badcase（FORMAT 和 JUDGE 均通过的轮次中，得分偏低的案例）

有效评分轮次中，质量分最低的几条（均为 85 分，并非真正的 badcase）：

| 模型 | 题材 | 质量分 | Judge 主要批评 |
|------|------|--------|--------------|
| ERNIE-5.0 | G04 玄幻修真 | 85 | 独特性不足，与同类修真题材雷同 |
| ERNIE-5.0 | G09 重生复仇 | 85 | 复仇动机设定较套路化 |
| DeepSeek-V3.2 | G05 悬疑反转 R3* | 20* | judge_err（排除） |

> **结论**：在 Judge 成功的轮次中，未发现真正的内容质量 badcase（最低分 85/100）。**主要问题是格式稳定性，而非内容创作质量。**
