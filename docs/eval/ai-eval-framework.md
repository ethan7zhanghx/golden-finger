# 金手指 AI 剧本写作质量评测框架 v1.0

**制定日期**: 2026-04-10
**适用产品**: 金手指微短剧 AI 创作辅助
**覆盖步骤**: worldview（世界观）/ selling_point（卖点）/ hook（爽点&钩子）

---

## 1. 评测目标与范围

### 1.1 评测目标

当前评测框架（仅 schema_pass_rate + 内容字段数量统计）存在根本性缺陷：**它无法区分"符合格式的垃圾输出"与"真正有商业价值的内容"**。

本框架针对微短剧 AI 写作产品的核心商业目标设计，需要回答以下问题：

1. 模型输出的世界观/卖点/爽钩是否**真正对编剧有参考价值**？
2. 生成的内容是否**符合目标受众的审美预期**？
3. 不同模型在**不同题材/受众**下各有什么优劣？
4. 当 prompt 或模型升级时，是否有**质量回归**？

### 1.2 评测的三个层次

| 层次 | 名称 | 说明 | 自动化程度 |
|------|------|------|-----------|
| L1 | 结构合规 | JSON schema 通过率、必填字段完整性 | 100% 自动 |
| L2 | 内容质量 | 多维度内容 rubric + LLM-as-Judge | 自动+LLM |
| L3 | 商业价值 | 人工标注、编剧专家评审 | 人工 |

## 3. 分步骤评分 Rubric

### 3.1 世界观（worldview）— 满分 100 分

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| **结构合规** | 20 | JSON schema 完整，所有必填字段存在且类型正确 |
| **具体性** | 20 | era_setting 有具体时间地点；social_rules 有机制细节，非泛泛描述 |
| **内部一致性** | 20 | 时代背景/社会规则/核心冲突三者逻辑自洽，无矛盾 |
| **可拍摄性** | 15 | visual_style 有画面感，适合实际拍摄预算和场景 |
| **题材契合度** | 15 | 与输入的 genre/audience 高度匹配 |
| **独特性** | 10 | unique_elements 真正区别于同类，非套话 |

**评分说明**：
- 结构合规：自动打分（pass=20，fail=0）
- 其余维度：LLM-as-Judge（见第 4 节），人工校准

### 3.2 卖点（selling_point）— 满分 100 分

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| **结构合规** | 15 | JSON schema 完整 |
| **Logline 打击力** | 25 | 一句话内包含主角+冲突+情感钩子；读完有"想看"冲动 |
| **卖点可信度** | 20 | selling_points 的 audience_appeal 说明是真实痛点/爽点，非自说自话 |
| **市场差异化** | 20 | differentiation 明确指出与同类的本质区别，可验证 |
| **优先级合理性** | 10 | priority 排序与市场逻辑一致（最吸引目标受众的排 1） |
| **覆盖度** | 10 | 卖点数量 3-5 个，覆盖情感、冲突、视觉至少 2 个维度 |

### 3.3 爽点&钩子（hook）— 满分 100 分

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| **结构合规** | 15 | JSON schema 完整 |
| **爽点具体性** | 20 | highlights 描述到场景级，能看到具体画面，非"逆袭类场景" |
| **钩子追更驱动力** | 20 | hooks 制造真实悬念，读完有强烈"想看下集"感 |
| **情绪类型多样性** | 15 | emotion_type 覆盖 3+ 种不同情绪（非全是"逆袭"） |
| **位置分布合理性** | 15 | position 在 opening/middle/climax/ending 均有分布 |
| **与卖点的呼应度** | 15 | hooks/highlights 与 selling_points 的核心卖点逻辑呼应 |

## 4. LLM-as-Judge 方案

### 4.1 Judge 模型

- 主 Judge：`claude-sonnet-4-6`（或当期最强可用模型）
- 备用 Judge：`ernie-5.0`（当 Claude 不可用时降级）
- 单独用于评分的模型**不参与生成**

### 4.2 Judge Prompt 模板（worldview 示例）

```
你是一位资深微短剧制片人和内容评审专家。请对以下 AI 生成的世界观设定卡进行专业评分。

【原始输入】
题材：{genre}，受众：{audience}
创意：{idea}

【AI 生成的世界观设定卡】
{worldview_json}

请对以下维度逐项打分（0-5分整数），并给出简短理由：
1. 具体性：设定是否足够具体、有画面感（0=空泛，5=极具体可落地）
2. 内部一致性：三者（背景/规则/冲突）是否逻辑自洽（0=矛盾明显，5=完全自洽）
3. 可拍摄性：是否适合短剧实际制作（0=无法拍摄，5=高度可执行）
4. 题材契合：是否符合{genre}+{audience}的定位（0=完全不符，5=高度匹配）
5. 独特性：是否真正有别于同类题材（0=高度雷同，5=高度原创）

输出格式（严格 JSON）：
{
  "scores": {"specificity": X, "consistency": X, "filmability": X, "genre_fit": X, "originality": X},
  "rationale": {"specificity": "...", "consistency": "...", "filmability": "...", "genre_fit": "...", "originality": "..."},
  "overall_comment": "一句话总评",
  "red_flags": ["严重问题列表，无则空数组"]
}
```

### 4.3 评分聚合

- 每个样本运行 3 次 Judge（降低随机性），取均值
- 自动打分维度（结构合规）不走 LLM
- 最终综合分 = 自动分 + LLM Judge 分，按权重合并

## 5. 指标体系

### 5.1 核心指标（必报）

| 指标 | 计算方式 | 说明 |
|------|---------|------|
| `schema_pass_rate` | pass/total | JSON 结构完整通过率 |
| `content_quality_p50` | 中位数综合分/100 | 内容质量中位数（分步骤） |
| `content_quality_p10` | P10 综合分 | 最差样本表现 |
| `genre_consistency` | 题材命中率 | Judge 评定是否符合题材 |
| `red_flag_rate` | 有 red_flag 样本/total | 严重问题发生率 |
| `latency_p50` | 中位延迟(ms) | 正常响应速度 |
| `latency_p95` | P95 延迟(ms) | 尾部延迟风险 |
| `token_cost_avg` | 平均 token 数 | 成本估算 |

### 5.2 Slice 维度（分层报告，不得只报平均值）

- **按题材**：G01~G10 各自独立报告
- **按步骤**：worldview / selling_point / hook
- **按模型**：ernie-5.0 / deepseek-v3.2 / claude-sonnet-4-6 / gpt-5.4
- **按受众**：18-25F / 25-35F / 20-35M / 混合

## 6. Release Gate（上线阈值）

| 指标 | 阻断阈值（BLOCKER） | 警告阈值（WARNING） |
|------|-------------------|--------------------|
| schema_pass_rate | < 90% | < 95% |
| content_quality_p50 | < 65/100 | < 75/100 |
| content_quality_p10 | < 45/100 | < 55/100 |
| red_flag_rate | > 10% | > 5% |
| latency_p95 | > 150s | > 100s |

**回归检测**：相比上一版 baseline，任何指标下降超过 5 分（绝对值）视为回归，需人工审查后方可上线。

## 7. 人工标注规范（L3 评测）

### 7.1 标注员资质

- 有微短剧/短视频内容行业经验（≥1年）
- 或有编剧/策划经验
- 最少 2 人交叉标注，计 Cohen's Kappa（目标 ≥0.7）

### 7.2 标注任务

1. **二元判断**：这个世界观/卖点/爽钩"值得编剧参考"吗？（Y/N）
2. **5分量表**：商业价值（1=完全没用，5=可以直接用）
3. **自由文本**：最大问题是什么？

### 7.3 人工标注频率

- 初始 baseline：全量 10 题材 × 3 步骤 × 每模型 5 轮 = 150 条/模型
- 后续回归检测：抽样 20% 或新增题材全量

## 9. 已知局限与诚实声明

| 局限 | 影响 | 缓解措施 |
|------|------|---------|
| LLM Judge 自评偏差 | Claude Judge 可能偏向 Claude 生成的输出 | 使用不同厂商 Judge 交叉验证 |
| 样本覆盖不足 | 10 题材不覆盖所有细分市场 | 持续扩展至 20+ 题材 |
| 无真实用户数据 | 不知道真实编剧是否满意 | Phase 2 引入人工标注 |
| 单轮评测 | 未测试多轮对话/迭代场景 | 后续加入多轮 eval |
